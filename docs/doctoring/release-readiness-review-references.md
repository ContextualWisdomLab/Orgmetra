- National Institute of Standards and Technology. - SLSA. (2025). *SLSA specification, version 1.2*. https://slsa.dev/spec/v1.2/ — approved specification released 2025-11-24; the 2026 date above is the evidence-review date, not the specification publication year.
- OWASP Foundation. (2025). *CycloneDX specification, version 1.7*. https://cyclonedx.org/specification/overview/ — current CycloneDX specification for software supply-chain transparency.

These references support evidence categories and acquisition-oriented release assurance. PR #118 does not claim SSDF certification, SLSA level attainment, CycloneDX conformance, signed provenance, or release authorization merely because a digest field exists.
