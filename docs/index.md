# Orgmetra

Orgmetra is an evidence-centered HRIS and HCM for the full employment lifecycle. It connects job architecture, recruiting evidence, employment records, performance outcomes, and validation evidence while preserving the time and ownership semantics needed for explainable workforce decisions.

## Start here

Run the repository baseline with the toolchain and commands documented in the [README](https://github.com/ContextualWisdomLab/Orgmetra#readme). The root validation path checks the repository manifest, foundation contract, OpenAPI structure, and dispatcher inventory; package-specific behavior has its own focused verification paths.

## Product responsibility

Orgmetra is the ContextualWisdomLab system of record for people, employment, organizations, jobs, positions, assignments, candidate-to-worker linkage, performance and criterion observations, workforce validation evidence, and governed talent-decision context.

It integrates with specialist products through versioned APIs, events, packages, and adapters rather than by taking ownership of their bounded contexts or directly querying their application tables.
