# User Stories

## HRIS administrator

- As an HRIS administrator, I need people, employment, positions, and assignments to be separate so that organization changes do not corrupt historical records.
- As an HRIS administrator, I need to create and retrieve an employment record after a candidate is linked to a worker so that hire completion is an explicit HRIS fact.
- As an HRIS administrator, I need effective time and system-recorded time so that audits can reconstruct what was true and what was known at a decision point.
- As an HRIS administrator, I need field-level access controls so that authorized HR work can use necessary PII without exposing it broadly.

## Job analyst

- As a job analyst, I need to collect web and internal evidence for a role so that a job profile is grounded rather than copied from a generic job posting.
- As a job analyst, I need to connect tasks to FJA and KSAO so that selection tools remain job-related.
- As a job analyst, I need SME review workflow so that AI-drafted task and KSAO claims are not published without human validation.

## Recruiter

- As a recruiter, I need candidate evidence mapped to job requirements so that screening is not keyword-only.
- As a recruiter, I need uncertainty and missing evidence clearly shown so that `unknown` is not treated as `not met`.
- As a recruiter, I need interview guides generated from the job profile and evidence gaps so that interviews are structured and defensible.

## Hiring manager

- As a hiring manager, I need to see the exact evidence behind a recommendation so that I can approve, reject, or request more evidence.
- As a hiring manager, I need decision records so that I can defend why a candidate was selected.

## People analytics scientist

- As a people analytics scientist, I need predictors and later criterion observations connected over time so that predictive validity can be studied.
- As a people analytics scientist, I need manager/team/opportunity/time context so that observed performance is not mistaken for pure individual ability.

## Compliance reviewer

- As a compliance reviewer, I need audit trails linking job profile, selection tool version, candidate evidence, human decision, and outcome evidence.
- As a compliance reviewer, I need proof that LLM outputs were draft evidence and not autonomous high-impact decisions.
