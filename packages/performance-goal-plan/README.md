# Orgmetra Performance Goal Plan

Status: **active pull-request slice; not protected-main truth until merged**.

This package defines value-minimized evidence for activating a reviewed employee performance-goal plan. The packet binds the exact tenant, Employment, Job, performance cycle, goal-set digest, measurement-definition digest, feedback cadence, requester, reviewer, and evidence version. Goal text, performance ratings, assessment scores, candidate data, compensation values, and employment decisions stay outside the envelope.

The packet is deliberately **not** a performance rating and **not** authority for promotion, pay, discipline, separation, or any other high-impact employment decision. A human reviewer must re-resolve the authoritative Employment, Job, cycle, actor identities, and exact goal/measurement definitions before activation.

The goal-set and measurement digests allow authorized application storage to keep usable goal content while durable governance evidence remains minimized and reproducible. Goal-setting research motivates explicit goal and feedback provenance, but Orgmetra does not infer that a goal is fair, valid, attainable, or employment-decision-worthy merely because the packet exists.
