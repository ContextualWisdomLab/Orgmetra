# Orgmetra Performance Goal Plan

Status: **stacked active pull-request slice; not protected-main truth until parent and child merge**.

This package defines value-minimized evidence for reviewing and, in the child activation lane, authoritatively activating an employee performance-goal plan. The reviewed packet binds the exact tenant, Employment, Job, performance cycle, goal-set digest, measurement-definition digest, feedback cadence, requester, reviewer, and evidence version. Goal text, performance ratings, assessment scores, candidate data, compensation values, and employment decisions stay outside the envelope.

The packet is deliberately **not** a performance rating and **not** authority for promotion, pay, discipline, separation, or any other high-impact employment decision. A human reviewer must be accountable for the reviewed plan. The activation boundary then requires that same reviewed human actor, approval no earlier than the plan evidence, and a fresh injected Orgmetra authority result that exactly rebinds tenant, Employment, Job, cycle, goal-set provenance, measurement provenance, and feedback cadence.

`activate_performance_goal_plan(...)` snapshots the sealed parent evidence before authority work, rejects duck-typed plan or verification objects, re-checks the parent creation seal after authority work, and emits a redacted `PerformanceGoalPlanActivationReceipt` only from the exact verified scope. The receipt remains `not_authorized_for_performance_rating` and `not_authorized_for_employment_decision`. Its process-local creation seal blocks low-level post-issuance object rewriting from creating a second canonical truth; durable cross-process uniqueness, database persistence, authorization, audit/outbox, and later rating or employment decisions remain separate authoritative responsibilities.

The goal-set and measurement digests allow authorized application storage to keep usable goal content while durable governance evidence remains minimized and reproducible. Goal-setting research motivates explicit goal and feedback provenance, but Orgmetra does not infer that a goal is fair, valid, attainable, or employment-decision-worthy merely because the packet or activation receipt exists.
